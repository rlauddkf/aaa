# PptCopy (프레젠테이션1 → OPT 붙여넣기 + 서식)

프로그램을 켜 둔 상태에서 **Ctrl + 숫자패드 +** 를 누르면:

1. 열려 있는 파워포인트 중 **`프레젠테이션1`** 창으로 전환해서 현재 선택된 부분을 복사 (`Ctrl+C`)
2. **`OPT`** 창으로 전환해서 현재 위치에 붙여넣기 (`Ctrl+V`)
3. 리본 **[테이블 디자인]** 탭의 버튼을 직접 누름
   - **음영 ▼ → 채우기 없음**
   - **테두리 ▼ → 모든 테두리**

   버튼은 Windows UI 자동화로 **이름을 찾아서** 누릅니다 (한국어/영어 오피스 모두, 리본 위치가 달라도 동작).
   버튼을 찾지 못하면 같은 서식(채우기 없음, 검은색 1pt 테두리)을 파워포인트에 직접 명령해서 적용합니다.

파일 이름은 확장자 없이 비교합니다 (`OPT.pptx` → `OPT`). 대소문자는 구분하지 않습니다.

## 사용법

1. `프레젠테이션1`과 `OPT` 파워포인트를 모두 열어 둡니다.
2. `PptCopy.exe`를 실행합니다 (설치 불필요, 단일 파일).
3. `OPT`에서 붙여넣을 위치(슬라이드 또는 표의 칸)를 선택해 둡니다.
4. `프레젠테이션1`에서 복사할 부분(표, 도형, 셀 등)을 선택합니다.
5. `Ctrl` + 숫자패드 `+` 를 누릅니다. 상태 창에 결과가 표시됩니다.

- 상태 창에 결과가 표시됩니다. 실행할 때마다 exe 옆에 `PptCopy_log.txt`가 생기고, 어떤 버튼을 찾았는지/눌렀는지 단계별로 적힙니다.
- ExcelCopy, SpaceMacro와 동시에 실행해도 됩니다.
- 파일 이름은 `ppt_copy.c` 상단의 `SRC_NAME`, `DST_NAME`으로 바꿀 수 있습니다.
- 모든 테두리의 두께·색은 리본의 **펜 두께 / 펜 색**에 현재 설정된 값으로 적용됩니다 (버튼을 직접 누를 때와 같음).

## 참고

- 파워포인트가 **관리자 권한**으로 실행 중이면 PptCopy도 관리자 권한으로 실행해야 합니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 직접 빌드

```bash
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows ppt_copy.c -o PptCopy.exe -lole32 -loleaut32 -luuid
```
