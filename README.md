# 평면도 3D 뷰어 (`viewer.html`)

표준 **4베이(4Bay) 아파트** 평면도를 3D로 자유롭게 회전·확대하며 각 실(방)의 치수를 확인하는 단독 실행 뷰어입니다.
외부 라이브러리 없이 순수 HTML/Canvas로 만든 3D 엔진이라 서버 없이 파일만 열면 됩니다.

- **열기**: `viewer.html`을 브라우저로 열기 (더블클릭 또는 파일 드래그). 모바일도 지원.
- **조작**: 드래그 = 회전, 마우스 휠/핀치 = 확대·축소, 우클릭 드래그(또는 두 손가락) = 이동
- **기능**: 벽 높이 조절, 치수/이름 표시 토글, 벽 반투명, 평면(위) 시점, 시점 초기화, 우측 목록에서 방 클릭 시 해당 방으로 카메라 이동
- **구성**: 앞줄(남향) 안방·거실·침실2·침실3 + 발코니, 뒤쪽 주방/식당·주방발코니·드레스룸·욕실1, 우측 현관·복도·욕실2·팬트리
- **치수**: 원본 도면(mm)의 실측값 적용 (욕실 1120×1586·1256×1586, 문 880·946·965·612, 창 1930·1515·1369·1450·1056 등)
- **데이터 수정**: `viewer.html` 상단 `rooms` / `doors` / `windows` 배열의 좌표(mm)를 고치면 도면 형상이 바뀝니다.

# Google Sheets Editor

Google Sheets 링크를 URL에 붙여넣으면 누구나 수정할 수 있는 웹 편집기입니다.  
서비스 계정(Service Account) 방식으로 개인 로그인 없이 동작합니다.

## 설정 (최초 1회)

### 1. Google Cloud 설정
1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. **APIs & Services → 라이브러리** → `Google Sheets API` 활성화
3. **APIs & Services → 사용자 인증 정보 → 서비스 계정 만들기**
4. 서비스 계정 생성 후 → **키 추가 → JSON** 다운로드
5. 다운로드한 파일 이름을 `credentials.json`으로 바꿔서 이 폴더에 복사

### 2. 스프레드시트 공유
- Google Sheets 열기 → **공유** 클릭
- `credentials.json` 안의 `client_email` 값을 복사해서 **편집자** 권한으로 공유

### 3. 서버 실행
```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 후  
Google Sheets URL을 붙여넣으면 바로 편집 가능합니다.

## 다른 사람과 공유

서버를 실행한 뒤 IP/도메인 주소를 공유하면  
**링크를 아는 누구나 로그인 없이 편집** 할 수 있습니다.

```
http://서버IP:3000
```

## 사용법

| 동작 | 방법 |
|------|------|
| 시트 열기 | URL 붙여넣고 **열기** 클릭 |
| 셀 편집 | 셀 클릭 후 바로 입력 (노란색 = 미저장) |
| 저장 | **저장** 버튼 또는 `Ctrl+S` |
| 시트 전환 | 상단 드롭다운에서 탭 선택 |
| 행 추가 | 테이블 하단 **+ 행 추가** 클릭 |
