# CAD 도면 2D → 3D 뷰어 (`viewer.html`)

업로드한 **AutoCAD DWG 도면(2018)** 을 브라우저에서 실제 그대로 2D로 보고, 벽을 **2300mm 고정 높이**로 세운 3D로 회전하며 볼 수 있는 단독 실행 뷰어입니다. 외부 라이브러리 없이 순수 HTML/Canvas로 만들어 서버 없이 파일만 열면 됩니다.

- **열기**: `viewer.html`을 브라우저로 열기 (더블클릭 또는 파일 드래그). 모바일(터치)도 지원.
- **2D 평면**: 도면의 실제 선형(벽·구획선)을 그대로 표시. 드래그 이동, 휠 확대·축소, `실명` 버튼으로 실명 텍스트 표시/숨김.
- **3D 입체**: `3D 입체` 버튼 → 모든 벽을 **2300mm**로 세운 입체 매싱. 드래그 회전, 휠 확대, 우클릭 드래그 이동.
- **화면맞춤**: 전체가 보이도록 맞춤.
- 도면은 세대별 평면 8개가 배치된 시트로, 약 55.5m × 91.3m, 직선 선형 34,235개를 담고 있습니다.

## 만든 과정
1. `LibreDWG`(소스 빌드)의 `dwg2dxf`로 DWG(AC1032, AutoCAD 2018) → DXF 변환
2. `ezdxf`로 DXF 파싱 — LINE / LWPOLYLINE / POLYLINE 선형과 TEXT(실명) 추출, 이상치 좌표 클리핑, mm 정수로 양자화하여 JSON(약 0.77MB)으로 임베드
3. 순수 Canvas 3D 엔진으로 2D 렌더링 + 2300mm 압출(extrude) 3D 매싱 렌더링

> 참고: 도면 레이어가 벽/가구를 구분하지 않아, 3D는 도면의 직선 선형 전체를 2300mm로 세운 **매싱(부피) 모델**입니다. 특정 세대 하나만 방 단위로 정리해 깔끔한 3D로 만들고 싶으면 말씀해 주세요.
