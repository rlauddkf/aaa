# 📈 미국장 단타 추천 프로그램

매일 저녁 **5시 30분(KST)** 에 알고리즘이 미국 시장(주식·ETF)을 분석해서
장중 단타(day-trading)에 가장 적합한 **최고 추천 종목 1개** 를 뽑아줍니다.

- API 키가 **필요 없습니다** (무료 공개 데이터: Yahoo Finance, 실패 시 Stooq 폴백)
- 롱/숏 매매 편향과 ATR 기반 손절·목표가 가이드까지 제공
- 결과는 콘솔 출력 + `logs/` 폴더에 자동 저장

---

## 방법 A. EXE로 쓰기 (코딩 없이, 추천)

프로젝트 폴더에 있는 배치 파일을 **더블클릭** 하면 됩니다.

1. **`1_EXE만들기.bat`** 더블클릭 → `dist\미국장단타추천.exe` 생성 (최초 1회)
2. 만들어진 **`dist\미국장단타추천.exe`** 더블클릭 → 오늘의 추천 종목이 바로 표시
3. (선택) **`2_매일자동실행_등록.bat`** 더블클릭 → 매일 저녁 5시 30분 자동 실행 등록
   - Windows 작업 스케줄러에 등록되어 창을 켜두지 않아도 됩니다.
   - 결과는 `dist\logs\` 폴더에 txt로 저장됩니다.
   - 해제하려면 `자동실행_해제.bat` 실행

## 방법 B. 명령어로 쓰기 (개발자용)

```bash
npm install          # 최초 1회

npm run recommend    # 지금 즉시 한 번 분석
npm run schedule     # 매일 저녁 5시 30분 자동 실행 (창을 켜둔 채 대기)
npm run build:exe    # exe 직접 빌드 → dist/미국장단타추천.exe
```

### exe 실행 모드 (인자)
| 실행 | 동작 |
|------|------|
| 그냥 더블클릭 / `exe` | 1회 분석 → 결과 표시 → 키 입력 대기 |
| `exe once-quiet` | 1회 분석 후 조용히 종료 (자동 실행용) |
| `exe schedule` | 매일 17:30 자동 실행, 창 켜둔 채 대기 |

## 알고리즘 (단타 적합도 스코어링)

장중 단타로 수익을 내려면 아래 조건이 골고루 좋아야 합니다.
각 요소를 0~100으로 정규화한 뒤 가중합으로 **종합 점수(0~100)** 를 계산합니다.

| 요소 | 가중치 | 의미 |
|------|:---:|------|
| 변동성 (ATR%) | 28% | 장중 움직임이 커야 먹을 게 있음 (스위트스팟 ≈ 3.5%) |
| 상대거래량 (RVOL) | 20% | 평소보다 거래가 몰리면 촉매/관심 → 방향성 발생 |
| 모멘텀 (5·10일) | 24% | 최근 추세가 살아있어야 방향성 매매가 쉬움 |
| 추세 정렬 (EMA20/50) | 16% | 가격·이평선 정렬이 깔끔할수록 가점 (롱·숏 무관) |
| RSI 위치 | 7% | 극단(과매수/과매도)보다 추세 지속 구간 선호 |
| 유동성 (거래대금) | 5% | 진입/청산 용이성 (로그 스케일 가점) |

또한 **평균 일 거래대금 5천만 달러 미만** 종목은 슬리피지 위험으로 후보에서 제외합니다(하드 필터).
매매 편향(LONG/SHORT/NEUTRAL)은 이평선 위치·최근 모멘텀·당일 종가 강도를 종합해 판정합니다.

> 가중치·필터 기준은 `stock/score.js` 상단 상수에서 자유롭게 조정할 수 있습니다.

## 설정 (환경변수)

`npm run schedule` 실행 시 아래 환경변수로 동작을 바꿀 수 있습니다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `REC_CRON` | `30 17 * * *` | 실행 시각(크론). 예: `0 18 * * 1-5` = 평일 18:00 |
| `REC_TZ` | `Asia/Seoul` | 타임존 |
| `RUN_NOW` | (없음) | `1` 이면 시작하자마자 1회 즉시 실행 |

예) 평일 저녁 6시에 실행하고 시작 시 즉시 1회도 실행:
```bash
REC_CRON="0 18 * * 1-5" RUN_NOW=1 npm run schedule
```

## 파일 구성

```
stock/
├── universe.js     분석 대상 종목/ETF 목록
├── dataSource.js   일봉 데이터 수집 (Yahoo → Stooq 폴백)
├── indicators.js   지표 계산 (ATR, RSI, EMA, RVOL, 모멘텀 등)
├── score.js        단타 적합도 스코어링 알고리즘
├── recommend.js    수집→계산→스코어→1위 선정→리포트 생성/저장
├── app.js          exe 진입점 (once / once-quiet / schedule 모드)
└── selftest.js     오프라인 알고리즘 검증 (npm run stock:test)
```
