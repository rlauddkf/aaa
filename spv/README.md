# SPV 파일 분석기

산업용 계측 장비가 남기는 `.SPV` 이진(binary) 시계열 로그 파일을 해석하고
그 내용을 사람이 읽을 수 있게 설명해 주는 프로그램입니다.
외부 라이브러리 없이 **파이썬 표준 라이브러리만으로** 동작합니다.

## 사용법

```bash
# 콘솔 요약 리포트
python3 spv_analyzer.py samples/TM095030.SPV

# CSV(엑셀에서 열기) + HTML 그래프 리포트 함께 생성
python3 spv_analyzer.py samples/TM095030.SPV --csv --html
```

옵션
| 옵션 | 설명 |
|------|------|
| `--csv [경로]`  | 전체 데이터를 CSV로 저장 (경로 생략 시 `입력파일명.csv`) |
| `--html [경로]` | 인라인 SVG 그래프가 담긴 HTML 리포트 생성 |
| `-q`, `--quiet` | 콘솔 리포트 생략 |

## 이 프로그램이 알려주는 것

- 측정 시작/종료 시각, 총 지속 시간, 샘플 간격, 총 샘플 수
- 블록 구성(블록별 시작 시각·샘플 수)
- 채널 6개(CH1~CH6)의 최소/최대/평균/표준편차와 파형 미리보기
- 실제로 변하는 "측정 신호" 채널과 값이 고정된 "기준/상태" 채널 구분

## 역설계로 밝혀낸 SPV 포맷

파일은 **512바이트 블록**의 연속입니다. (예: 3584B = 7블록)
각 블록 = **32바이트 헤더 + 480바이트 데이터**.

### 블록 헤더 (32바이트)

| 오프셋 | 타입 | 의미 |
|-------:|------|------|
| 0  | 4 bytes | 매직 `44 05 1A 08` (포맷 식별자, 모든 블록 동일) |
| 4  | uint8   | `0x18`(24) 고정 |
| 5  | uint8   | 시(hour) — 이 블록 첫 샘플 시각 |
| 6  | uint8   | 분(minute) |
| 7  | uint8   | 초(second) |
| 8  | uint16  | 샘플 간격(초) = 20 |
| 10 | uint16  | 블록 순번 (0,1,2 …) |
| 12 | uint16  | 0 (예약) |
| 14 | uint16  | 이 블록의 유효 레코드 수 (마지막 블록만 적음) |
| 16 | uint16  | 설정값1 = 261 |
| 18 | uint16  | 설정값2 = 1500 |
| 20 | int16   | 설정값3 = -600 |
| 22 | 10 bytes| 0 (패딩) |

### 데이터 레코드 (12바이트) × 유효 레코드 수

6개의 **int16 little-endian** 채널값 `CH1..CH6`.

- `CH1, CH2, CH3, CH5` — 실제로 변화하는 측정 신호
- `CH4, CH6` — 측정 중에는 고정값, 종료 구간에서 값이 바뀌는 기준/상태 채널

파일 이름 `TM095030` 은 `TM<시분초>` 규칙으로, 측정 시작 시각(09:50:30)을 담습니다.

> ⚠️ 각 채널의 **물리 단위**(전류·전압·힘 등)는 제조사 고유 규격이라 파일에
> 들어있지 않습니다. 컨테이너 구조·시간축·채널값은 위와 같이 완전히 복원됩니다.

## 예시 결과 (samples/TM095030.SPV)

- 측정 09:50:30 → 11:14:30 (약 1시간 24분), 20초 간격 **252 샘플**, 7블록
- CH1·CH2 는 주기적으로 오르내리는 파형, CH3 은 상승 후 포화, CH5 는 골 이후 상승
