▶ 처음 사용하시나요? 설정 가이드 보기
1
Google Cloud Console에서 Google Sheets API를 활성화하세요.
2
APIs & Services → 사용자 인증 정보 → OAuth 2.0 클라이언트 ID 생성 (유형: 웹 애플리케이션)
승인된 JavaScript 원본에 http://localhost:8080 또는 사용 중인 주소 추가
3
생성된 클라이언트 ID를 아래에 붙여넣으세요.
4
수정하려는 Google Sheets 링크를 붙여넣고 로그인하면 됩니다.
