# SpaceMacro (스페이스바 매크로)

스페이스바를 **한 번 누를 때마다 동작을 딱 한 번만** 실행하고 멈추는 Windows 프로그램입니다.
키는 **직전(현재 활성) 창**으로 보내집니다. 스페이스바를 다시 누르기 전에는 아무것도 하지 않습니다.

| 스페이스바 | 동작 |
|-----------|------|
| 1번째 누름 | ↑ 위 방향키 10번 → 스페이스바 → **정지(대기)** |
| 2번째 누름 | ↓ 아래 방향키 10번 → 스페이스바 → **정지(대기)** |
| 3번째 누름 | 다시 ↑ 위 동작 1회 → 정지 … |

매크로가 마지막에 보내는 스페이스바로 매크로가 다시 실행되지 않도록 막혀 있습니다.

## 사용법

1. `SpaceMacro.exe`를 실행합니다 (설치 불필요, 단일 파일).
2. 작은 상태 창이 항상 위에 뜹니다. 이 창은 클릭해도 포커스를 가져가지 않습니다.
3. 매크로를 적용할 창을 클릭해서 활성화한 뒤 스페이스바를 누릅니다.

| 키 / 버튼 | 기능 |
|-----------|------|
| `Space` | 매크로 실행 (원래 스페이스 입력은 막힘) |
| `F8` | 일시정지 / 재개 (일시정지 중엔 스페이스바가 평소처럼 입력됨) |
| `Shift/Ctrl/Alt + Space` | 매크로 없이 그대로 통과 (한/영 전환 등) |
| `종료` 버튼 | 프로그램 종료 |

## 참고

- Windows 7 이상 64비트에서 동작합니다. 별도 런타임이 필요 없습니다(정적 링크).
- 대상 프로그램이 **관리자 권한**으로 실행 중이면 SpaceMacro도
  마우스 오른쪽 클릭 → **관리자 권한으로 실행** 해야 키가 전달됩니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
- 반복 횟수·키 간격은 `space_macro.c` 상단의 `REPEAT_COUNT`, `KEY_GAP_MS`로 조절할 수 있습니다.

## 직접 빌드

```bash
# Linux (MinGW-w64)
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows space_macro.c -o SpaceMacro.exe
```

Windows에서는 MSYS2/MinGW의 `gcc`로 같은 명령을 사용하면 됩니다.
