# ExcelCopy (엑셀 → 파워포인트 반복 붙여넣기)

프로그램을 켜 둔 상태에서 **Ctrl+Shift를 누르는 즉시** 아래 동작을 **3번 반복**합니다.

| 순서 | 창 | 동작 |
|------|----|------|
| 1 | 엑셀 | `Ctrl+Shift+↓` (아래로 데이터 끝까지 선택) → `Ctrl+C` (복사) |
| 2 | 파워포인트 | 창 전환 → `Ctrl+V` (붙여넣기) → `→` 1번 |
| 3 | 엑셀 | 창 전환 → `→` 19번 |
| | | 1~3을 총 3회 반복 (**마지막 3회차는 3번을 생략**하고 파워포인트에서 끝남) |

각 단계는 고정된 대기시간 없이 **복사 완료, 창 전환 완료, 프로그램의 입력 처리 완료**를
확인하는 즉시 다음 단계로 넘어갑니다.

## 사용법

1. 엑셀과 파워포인트를 모두 열어 둡니다.
2. `ExcelCopy.exe`를 실행합니다 (설치 불필요, 단일 파일).
3. 파워포인트에서 붙여넣을 위치(슬라이드)를 선택해 둡니다.
4. 엑셀에서 시작할 셀을 클릭합니다.
5. `Ctrl`과 `Shift`를 함께 누르면 바로 실행됩니다. 상태 창에 `실행 중 1/3`처럼 진행 상황이 표시됩니다.

| 키 / 버튼 | 기능 |
|-----------|------|
| `Ctrl+Shift` 누르기 | 매크로 즉시 실행 (계속 누르고 있어도 1번만 실행) |
| `Esc` | 실행 중 중지 |
| `F9` | 일시정지 / 재개 |
| `종료` 버튼 | 프로그램 종료 |

- 엑셀/파워포인트 창이 여러 개면 **마지막으로 사용한 창**을 대상으로 합니다. 상태 창에 대상 파일 이름이 표시됩니다.
- SpaceMacro와 동시에 실행해도 됩니다 (SpaceMacro는 F8, ExcelCopy는 F9 사용).
- 반복 횟수와 방향키 횟수는 `excel_copy.c` 상단의 `LOOP_COUNT`, `PPT_RIGHT_COUNT`, `EXCEL_RIGHT_COUNT`로 바꿀 수 있습니다.

## 참고

- Ctrl+Shift만 눌러도 바로 실행되므로, 프로그램이 켜져 있는 동안에는 `Ctrl+Shift+다른 키` 단축키를 쓰기 어렵습니다.
  필요할 때는 `F9`로 일시정지하세요.
- Windows에 입력 언어가 여러 개 설치돼 있고 **Ctrl+Shift가 언어 전환 단축키**로 설정돼 있으면
  매크로를 실행할 때 언어도 함께 바뀔 수 있습니다.
  설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 입력 언어 단축키에서 끄면 됩니다.
- 엑셀/파워포인트가 **관리자 권한**으로 실행 중이면 ExcelCopy도 관리자 권한으로 실행해야 합니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 직접 빌드

```bash
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows excel_copy.c -o ExcelCopy.exe
```
