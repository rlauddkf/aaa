# ExcelCopy (엑셀 열 → 파워포인트 슬라이드 붙여넣기)

엑셀에서 선택한 셀의 **행 번호**를 읽고, 정해진 열들을 그 행부터 아래로 복사해서
파워포인트의 **클릭해 둔 위치**에 차례대로 붙여넣습니다.

## 동작 순서

| 슬라이드 | 복사할 열 (선택 행부터 아래로 끝까지) | 파워포인트 |
|---------|------------------------------|-----------|
| 1 | `D` → `AA` → `AX` | 클릭해 둔 위치에 붙여넣기 → `→` 1번 (열마다) |
| 2 | `K` → `AH` → `BE` | `PageDown` 후 같은 위치 클릭, 붙여넣기 → `→` 1번 (열마다) |
| 3 | `S` → `AP` → `BM` | `PageDown` 후 같은 위치 클릭, 붙여넣기 → `→` 1번 (열마다) |

- 복사 범위는 그 행의 셀에서 `Ctrl+Shift+↓`를 누른 것과 같습니다.
- 엑셀 복사는 **엑셀에 직접 연결(COM)** 해서 처리하므로 엑셀 창으로 전환하지 않습니다.
  파워포인트 창이 계속 앞에 있어서 빠르고, 방향키로 열을 옮기지 않아 열 위치가 틀어지지 않습니다.

## 사용법

1. 엑셀과 파워포인트를 모두 열어 둡니다.
2. `ExcelCopy.exe`를 실행합니다 (설치 불필요, 단일 파일).
3. **파워포인트**에서 붙여넣을 칸(표의 셀 등)을 클릭합니다. → 위치가 기록됩니다.
4. **엑셀**에서 복사할 행의 셀을 클릭합니다 (어느 열이든 상관없음, 행 번호만 사용).
5. `Ctrl`과 `Shift`를 함께 누르면 바로 실행됩니다.

| 키 / 버튼 | 기능 |
|-----------|------|
| `Ctrl+Shift` 누르기 | 매크로 즉시 실행 |
| `Esc` | 실행 중 중지 |
| `F9` | 일시정지 / 재개 |
| `종료` 버튼 | 프로그램 종료 |

- 상태 창에 읽은 행 번호, 진행 상황(`슬라이드 2/3 · AH열`), 결과가 표시됩니다.
- 실행할 때마다 exe와 같은 폴더에 `ExcelCopy_log.txt`가 생깁니다. 단계별로 무엇을 했는지
  (복사한 범위 주소 등) 적혀 있어서, 문제가 생기면 이 파일 내용을 보면 원인을 알 수 있습니다.
- 열 목록과 슬라이드 수는 `excel_copy.c` 상단의 `COLUMNS`, `PAGE_COUNT`로 바꿀 수 있습니다.

## 참고

- 엑셀에서 **셀을 편집 중**(커서가 셀 안에서 깜빡이는 상태)이면 엑셀이 연결을 거부해서 복사에 실패합니다.
  Enter나 Esc로 편집을 끝낸 뒤 실행하세요.
- 엑셀을 막 실행한 직후에는 연결이 안 될 수 있습니다. 다른 창을 한 번 클릭했다가 돌아오면 됩니다
  (PPT 위치를 먼저 클릭하는 순서면 자연스럽게 해결됩니다).
- 실행 중에는 파워포인트 창을 옮기거나 확대/축소하지 마세요. 기록한 클릭 위치가 화면 좌표라 어긋날 수 있습니다.
- 클릭 위치는 **파워포인트 창 안에서 마지막으로 클릭한 곳**입니다. 붙여넣을 칸을 클릭한 뒤 다른 곳을 클릭하지 마세요.
- Ctrl+Shift만 눌러도 바로 실행되므로, 프로그램이 켜져 있는 동안에는 `Ctrl+Shift+다른 키` 단축키를 쓰기 어렵습니다.
  필요할 때는 `F9`로 일시정지하세요.
- Windows에서 **Ctrl+Shift가 입력 언어 전환 단축키**로 설정돼 있으면 언어도 함께 바뀔 수 있습니다.
  설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 입력 언어 단축키에서 끄면 됩니다.
- 엑셀/파워포인트가 **관리자 권한**으로 실행 중이면 ExcelCopy도 관리자 권한으로 실행해야 합니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 직접 빌드

```bash
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows excel_copy.c -o ExcelCopy.exe -lole32 -loleaut32 -luuid
```
