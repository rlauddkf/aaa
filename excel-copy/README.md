# ExcelCopy (엑셀 아래로 선택 후 복사)

프로그램을 켜 둔 상태에서 **Ctrl+Shift를 눌렀다 떼면** 엑셀 창에서 아래 동작을 자동으로 실행합니다.

1. `Ctrl+Shift+↓` : 현재 셀부터 아래로 데이터가 끝나는 곳까지 선택
2. `Ctrl+C` : 선택한 영역 복사

## 사용법

1. `ExcelCopy.exe`를 실행합니다 (설치 불필요, 단일 파일).
2. 엑셀에서 시작할 셀을 클릭합니다.
3. `Ctrl`과 `Shift`를 함께 눌렀다가 뗍니다. 선택과 복사가 끝나면 원하는 곳에 `Ctrl+V`로 붙여넣으면 됩니다.

| 키 / 버튼 | 기능 |
|-----------|------|
| `Ctrl+Shift` 눌렀다 떼기 | 매크로 실행 |
| `Ctrl+Shift+다른 키` (예: `Ctrl+Shift+↓`, `Ctrl+Shift+클릭`) | 원래대로 동작 (매크로 실행 안 됨) |
| `F9` | 일시정지 / 재개 |
| `종료` 버튼 | 프로그램 종료 |

- 엑셀이 활성 창이 아니면 마지막으로 사용한 엑셀 창을 앞으로 가져온 뒤 실행합니다.
- SpaceMacro와 동시에 실행해도 됩니다 (SpaceMacro는 F8, ExcelCopy는 F9 사용).

## 참고

- Windows에 입력 언어가 여러 개 설치돼 있고 **Ctrl+Shift가 언어 전환 단축키**로 설정돼 있으면
  매크로를 실행할 때 언어도 함께 바뀔 수 있습니다.
  설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 입력 언어 단축키에서 끄면 됩니다.
- 엑셀이 **관리자 권한**으로 실행 중이면 ExcelCopy도 관리자 권한으로 실행해야 합니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 직접 빌드

```bash
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows excel_copy.c -o ExcelCopy.exe
```
