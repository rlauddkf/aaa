# ExcelPptDown (엑셀 열 → 파워포인트 아래로 붙여넣기, 페이지 반복)

프로그램을 켜 둔 상태에서 **Ctrl + 숫자패드 -** 를 누르면 아래 동작을 실행합니다.

### 한 페이지 (페이지당 횟수만큼 반복, 기본 6회)

| 순서 | 창 | 동작 |
|------|----|------|
| 1 | 엑셀 | 선택된 셀부터 아래로 데이터 끝까지 복사 (`Ctrl+Shift+↓` 범위) |
| 2 | 파워포인트 | 찍어 둔 위치(이어서 진행 중인 위치)에 붙여넣기 (`Ctrl+V`) → `↓` 1번 |
| 3 | 엑셀 | `→` 1번 (다음 열) |

### 다음 페이지

파워포인트에서 `Esc` ×3 → `PageDown` (다음 슬라이드) → **처음에 찍은 위치와 같은 곳을 찍고** 이어서 진행합니다.
엑셀은 멈춘 열의 다음 열부터 계속 이어집니다.

- 페이지 수와 페이지당 횟수는 상태 창의 입력칸에서 정합니다 (각각 1~99, 자동 저장).
- 엑셀 시작 셀이 **비어 있으면** 데이터가 끝난 것으로 보고 멈춥니다.
- 맨 마지막 회차 뒤의 엑셀 `→`는 생략합니다.
- 엑셀은 **직접 연결(COM)** 해서 처리하므로 엑셀 창으로 전환하지 않습니다. 파워포인트 창이 계속 앞에 있어서 빠릅니다.
- 엑셀의 `→` 이동은 키보드처럼 숨긴 열을 건너뜁니다.

## 사용법

1. 엑셀과 파워포인트를 모두 열어 둡니다.
2. `ExcelPptDown.exe`를 실행합니다 (설치 불필요, 단일 파일).
3. 상태 창에서 **페이지 수**와 **페이지당 횟수**를 확인합니다.
4. **파워포인트**에서 붙여넣을 칸을 클릭합니다. → 위치가 기록됩니다 (상태 창에 "기록됨" 표시).
5. **엑셀**에서 시작할 셀을 클릭합니다.
6. `Ctrl` + 숫자패드 `-` 를 누릅니다. 상태 창에 `페이지 2/3 · 4/6회`처럼 진행 상황이 표시됩니다.

| 키 / 버튼 | 기능 |
|-----------|------|
| `Ctrl` + 숫자패드 `-` | 매크로 실행 |
| `Esc` | 실행 중 중지 |
| `종료` 버튼 | 프로그램 종료 |

- 실행할 때마다 exe 옆에 `ExcelPptDown_log.txt`가 생기고, 회차마다 복사한 범위 주소 등이 적힙니다.
- ExcelCopy(Ctrl+Shift), PptCopy(Ctrl+숫자패드 +), SpaceMacro와 동시에 실행해도 됩니다.

## 참고

- 클릭 위치는 **파워포인트 창 안에서 마지막으로 클릭한 곳**입니다. 붙여넣을 칸을 클릭한 뒤 파워포인트의 다른 곳을 클릭하지 마세요.
- 실행 중에는 파워포인트 창을 옮기거나 확대/축소하지 마세요. 기록한 클릭 위치가 화면 좌표라 어긋날 수 있습니다.
- 엑셀에서 **셀을 편집 중**이면 엑셀이 연결을 거부해서 복사에 실패합니다. Enter나 Esc로 편집을 끝낸 뒤 실행하세요.
- 엑셀을 막 실행한 직후에는 연결이 안 될 수 있습니다. 다른 창을 한 번 클릭했다가 돌아오면 됩니다.
- 엑셀/파워포인트가 **관리자 권한**으로 실행 중이면 이 프로그램도 관리자 권한으로 실행해야 합니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 직접 빌드

```bash
x86_64-w64-mingw32-gcc -O2 -s -static -municode -mwindows excel_ppt_down.c -o ExcelPptDown.exe -lole32 -loleaut32 -luuid
```
