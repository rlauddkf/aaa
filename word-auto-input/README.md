# 워드 표 양식 자동 입력기 (Windows · Word 연결 방식)

**실행 중인 Word 문서에 직접 연결(win32com)** 하여,
현재 **커서가 놓인 표의 셀 위치를 인식**하고 그 열을 따라 아래로 값(숫자 등)을 채웁니다.
설정한 개수(기본 **30개**)마다 **최초 양식(표)을 서식 그대로 정확히 복제**하여
새 페이지에 삽입하고, 그 페이지에서 이어서 계속 채웁니다.

> 키 입력을 흉내내는 방식이 아니라 Word를 직접 제어하므로 **포커스 전환/타이밍 문제 없이 정확**합니다.

예) `1~50` 입력 → 1페이지 표에 1~30 (커서 열을 따라 아래로) → 최초 양식을 새 페이지에 그대로 복제 → 31~50 이어서 입력

---

## 1. 설치 (Windows + Microsoft Word 필요)

명령 프롬프트(cmd)에서:

```bash
pip install pywin32
```

## 2. 실행

```bash
python word_auto_input.py
```

## 3. 사용 순서

1. **Word에서 표 양식 문서를 연다.**
2. 숫자를 넣기 시작할 **첫 번째 칸을 클릭**해서 커서를 둔다.
3. 프로그램 입력창에 **숫자를 한 줄에 하나씩** 붙여넣는다.
4. **[워드 연결 확인]** 을 눌러 문서 이름과 커서 위치(예: `3행 2열`)가 잡히는지 확인한다.
5. **[시작]** 을 누른다. 끝!

포커스를 옮기거나 기다릴 필요가 없습니다. 프로그램이 Word를 직접 조작합니다.

---

## 4. 동작 방식 (정확도의 핵심)

1. 커서가 있는 **셀의 행/열 좌표**와 그 **표**를 인식합니다.
2. 필요한 페이지 수만큼, **아직 비어 있는 최초 양식**을 문서 끝에 `FormattedText`로 **서식 그대로 복제**합니다.
   (표 테두리·너비·글꼴 등 그대로. 페이지마다 `페이지 나누기`로 분리)
3. 각 페이지 표의 **같은 열(커서가 있던 열)** 을 따라 위→아래로 값을 채웁니다.
   시작 행도 커서가 있던 행과 동일하게 맞춥니다.

즉, "커서 위치 인식 → 아래로 채우기 → 30개마다 양식 정확 복제 → 이어서 진행"이 그대로 구현됩니다.

## 5. 설정

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 페이지당 개수 | 몇 개마다 새 페이지 양식을 추가할지 | 30 |
| 복제할 양식 범위 | `table`: 커서가 있는 표만 복제 / `page`: 커서가 있는 페이지 전체 복제 | table |

- 양식이 **표 하나**면 `table` 로 두세요(가장 정확).
- 표 위/아래에 제목·설명 등 다른 요소가 있고 그것까지 통째로 복제하려면 `page` 를 선택하세요.

## 6. 자주 묻는 문제

- **연결 실패 / 열린 문서가 없습니다** → Word를 먼저 실행하고 문서를 연 뒤 다시 시도.
- **커서를 표 안의 첫 칸에 두세요** → 시작 전에 반드시 표 셀을 클릭해 커서를 넣어야 합니다.
- **`pip install pywin32` 후에도 오류** → 관리자 cmd에서 `python Scripts\pywin32_postinstall.py -install` 실행 후 재시도.
- **값이 다른 칸에 들어감** → 커서를 정확히 "숫자가 시작될 칸"에 두고 [워드 연결 확인]으로 행/열을 확인하세요.
- **여러 Word 문서가 열려 있음** → 값을 채울 문서를 **맨 앞(활성)** 으로 두세요. 활성 문서에 입력됩니다.

## 7. 참고
- Windows + 데스크톱용 Microsoft Word 에서만 동작합니다(웹/모바일 불가).
- macOS 는 이 COM 방식이 없어 별도 구현이 필요합니다(필요 시 요청 주세요).
