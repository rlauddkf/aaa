# 워드 표 양식 자동 입력기 (Windows)

여러 줄로 입력한 값(예: 숫자 `1,2,3,4,5...`)을 **이미 열려 있는 Word 문서의 커서 위치부터**
자동으로 타이핑하고, 각 값마다 **아래키**로 다음 칸(표의 아래 셀)으로 이동합니다.

설정한 개수(기본 **30개**)마다 **새 페이지에 빈 표 양식을 붙여넣고** 이어서 계속 작성합니다.

> 예) `1~50` 을 넣으면 → 1페이지에 1~30 (한 칸씩 아래로) → 새 페이지에 표 양식 추가 → 31~50 이어서 입력

---

## 1. 설치

Windows에 Python 3가 설치되어 있어야 합니다. (설치 시 "Add Python to PATH" 체크)

명령 프롬프트(cmd)에서:

```bash
pip install pyautogui pyperclip
```

## 2. 실행

```bash
python word_auto_input.py
```

## 3. 사용 순서

1. **Word에서 표 양식 문서를 연다.**
2. **빈 표 양식 하나를 통째로 선택 → `Ctrl+C`** 로 복사해 둔다.
   (30개마다 새 페이지에 이 표를 붙여넣습니다. → "표 양식 붙여넣기" 옵션 사용 시)
3. 프로그램 입력창에 **숫자를 한 줄에 하나씩** 붙여넣는다.
4. **[시작]** 을 누른다.
5. 카운트다운(기본 5초) 동안 **Word 창으로 전환해 첫 번째 숫자 칸을 클릭**한다.
6. 손을 떼고 기다린다. 자동으로 입력됩니다.

### 중단하는 법
- **[Stop]** 버튼을 누르거나
- **마우스를 화면 왼쪽 위 구석으로 휙 옮기면** 즉시 멈춥니다(pyautogui 안전장치).

---

## 4. 설정 항목

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 페이지당 개수 | 몇 개마다 새 페이지 양식을 추가할지 | 30 |
| 다음 칸 이동 키 | 값 입력 후 이동할 키 (표는 보통 `down`) | down |
| 위로 이동 횟수(복귀) | 새 표를 붙여넣은 뒤 첫 칸으로 올라갈 횟수 | 페이지당 개수와 동일(자동) |
| 키 입력 간격(초) | 값 사이 지연 (너무 빠르면 누락 시 늘리세요) | 0.05 |
| 시작 대기(초) | 시작 후 Word로 전환할 시간 | 5 |
| 표 양식 붙여넣기 | 30개마다 `Ctrl+End → 페이지나누기 → Ctrl+V → 위로이동`으로 표 재삽입 | 켜짐 |

---

## 5. "위로 이동 횟수" 보정 (표마다 1회만 맞추면 됩니다)

새 표를 붙여넣은 직후, 커서는 보통 **표 바로 아래**에 놓입니다.
프로그램은 `위로 이동 횟수`만큼 `↑` 를 눌러 **첫 번째 숫자 칸**으로 되돌아갑니다.

- 표의 숫자 칸이 **정확히 30줄(=페이지당 개수)** 이고 그 아래에 다른 내용이 없다면 → 자동값(30)으로 맞습니다.
- 첫 칸에 정확히 안 오면 **"위로 이동 횟수 = 페이지당 개수(자동)"** 체크를 끄고 값을 **±1~2** 조정해 보세요.
- 한 번만 맞추면 이후 모든 페이지에 동일하게 적용됩니다.

> 팁: 처음에는 숫자를 `1~60` 정도만 넣고 테스트해서 2페이지 넘어갈 때 첫 칸에 잘 복귀하는지 확인하세요.

---

## 6. 자주 묻는 문제

- **숫자가 한글로 바뀌어 입력됨** → 입력 전 키보드를 **영문 상태**로 두세요. (숫자는 보통 IME 영향이 없지만 안전하게)
- **일부 값이 누락됨** → `키 입력 간격`을 `0.1~0.2`로 늘리세요.
- **표가 안 붙여짐** → 실행 전에 빈 표를 `Ctrl+C` 했는지 확인. 다른 걸 복사하면 클립보드가 바뀝니다.
- **커서가 엉뚱한 곳에 감** → `위로 이동 횟수`를 보정하세요(위 5번).
